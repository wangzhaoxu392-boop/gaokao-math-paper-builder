# 题库工作流

## 输入分类

文件角色固定为 `question`、`answer`、`solution`、`rubric`、`mixed` 或 `unknown`。一个考试资料包可以关联多个题卷源、多个答案源和多个解析源。

## 入库顺序

1. 计算文件 SHA-256，相同内容不重复登记。
2. 安全解压压缩包；拒绝路径穿越、符号链接、异常压缩比和超量内容。
3. 提取文字并保留原始文件。无文字层、公式异常或依赖图形时标记复核。
4. 为资料包识别年级、学期、卷型、地区、课程版本、总分、时长和命题范围。
5. 分别拆出题目、答案和解析；用小问编号和内容指纹建立映射。
6. 题目、答案和图形进入复核页。缺少可靠对应关系时不得自动确认。
7. 保存题目后重建索引。

支持的散装来源包括 PDF、DOCX、Markdown、TXT、图片和常见压缩包。Markdown 只作为数据处理，不执行链接、脚本或内嵌 HTML。

拆题规则 v3 将题目区、答题说明、内嵌答案解析和参考答案附加区分开。遇到 `【答案】`、`【解析】`、`【详解】`、`参考答案`、`【N题答案】` 或下一份试卷边界时结束当前题干。大题声明的小题数用于校验题号顺序。

答题说明、答案步骤、参考答案附加区、无完整设问的记录和已有子问题的父题容器只做逻辑删除，保留旧记录、来源和排除代码。清理流程必须先预检、再快照、重新解析、答案对齐和重建索引。

窗口的“保存到资料库”会立即执行上述登记，而不是等待生成试卷。每个压缩包形成独立资料包，题卷立即拆成草稿题；配对和答案映射随后执行。

## 题答配对

试卷和答案优先使用人工指定的资料包关系。自动建议综合以下信号：

- 文件标题、年份、地区、学校、年级和卷型。
- 题号数量、题型顺序和小问编号。
- 题干与答案内容的相似度。
- 原始压缩包目录和文件前缀。

自动建议不能覆盖人工确认，也不能仅凭文件名相同就确认配对。多对多关系必须保存为显式链接。

每个题卷最多保留三个候选答案。同一压缩包内来源优先；用户确认后才将答案写入题目。

答案状态：

- `matched`：题号、内容和版本一致。
- `partial`：只覆盖率部分题型或小问。
- `missing`：未找到答案。
- `conflicting`：多个来源答案不一致。
- `mismatch`：疑似对应对应另一份试卷。
- `verified`：来源确认或独立求解复核通过。

答案解析必须同时支持紧排答案表、逐题答案表、`【答案】`、`【解析】`、`【详解】`、多选题字母组合和小问答案。答案标签与完整解析分开保存，二者文字不同不构成冲突。

缺答案题先执行确定性回填。仍有真实缺题时，L1–L3 纯文本题可由本地模型先解；图形、L4/L5、证明构造和分歧题升级到当前云端模型。两次独立答案一致后才设为 `verified`；仍不一致时进入人工，不直接删除。

审核页按“人工例外、缺答案、随机抽查、系统排除、全部”分队列。批量批准扫描当前筛选全部分页，异常题逐条跳过并报告。

窗口默认启用零人工审核：低风险且结构、答案、媒体完整的题自动通过。定时复检中的本地或线上模型分歧必须保留记录并进入人工，不得仅因单次模型失败自动删除；只有结构证据明确表明题目不可修复时才允许记录 `auto_unverified`。待复核队列不得作为与当前试卷无关的全局组卷阻断项。

窗口常规组卷走确定性快速路径：直接使用 `plan` 选题并 `render` 输出，不启动 Codex 代理。`auto_relax_bands=true` 时允许使用相邻一档的已审核题补足目标题位，并在 selection 中记录 `band_fallback=true`。

## 复核优先级

必须优先复核：

- 扫描件、手写批注和图形依赖题。
- 题目与答案数量不一致、题号异常或版本冲突。
- L4、L5、证明、构造和多解法题。
- 旧教材、跨学期和不在目标考试范围内的题。
- 本地模型置信度低或与规则明显冲突的题。

## 导入格式

`paperbank.py import-items` 接受 JSON 数组。每个对象遵循 `scripts/item.schema.json`。没有明确来源的原创题可以用 `source_authority: "ai_generated"`，但不得伪装成真题。
